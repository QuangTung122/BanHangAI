# Prompts (Mẫu chỉ thị AI)

Thư mục này chứa thư viện các mẫu prompt (chỉ thị cho AI) được phân loại và thiết kế bài bản theo từng giai đoạn trong vòng đời phát triển phần mềm (SDLC). Những prompt này giúp các Agent hoặc LLM hỗ trợ tự động hóa các khâu xây dựng dự án BanHangAI.

## 📁 Cấu trúc thư mục

- **`analysis/`**: Các prompt phục vụ phân tích nghiệp vụ, gợi ý thiết kế (Yêu cầu, ERD, Wireframe, Use Cases).
- **`design/`**: Các prompt phục vụ thiết kế kiến trúc hệ thống, API Specs, giao diện UI và quy trình nghiệp vụ (POS, Trả góp, Nhân viên,...).
- **`development/`**: Các prompt hỗ trợ sinh mã nguồn (Backend Express, CRUD APIs, POS View, Tích hợp AI).
- **`testing/`**: Các prompt sinh test case và kịch bản kiểm thử cho các module.
- **`documentation/`**: Các prompt tạo tài liệu dự án (README, Demo Script, Slides, Deployment Guide).
