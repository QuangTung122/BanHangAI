# Docs (Tài liệu dự án)

Thư mục này chứa các tài liệu hướng dẫn (Guides), vận hành (Operations) và thiết lập (Setup) cho dự án BanHangAI.

## 📁 Cấu trúc thư mục

- **`guides/`**: Tài liệu hướng dẫn sử dụng và thuyết trình.
  - `demo-script.md`: Kịch bản demo bán hàng và các tính năng AI.
  - `presentation-slides.md`: Nội dung slide thuyết trình về dự án.
- **`operations/`**: Tài liệu vận hành và triển khai.
  - `deployment-guide.md`: Hướng dẫn triển khai, đóng gói Docker và quản lý môi trường.
- **`setup/`**: Hướng dẫn cài đặt môi trường và chuẩn bị dữ liệu mẫu (hiện tại có thể tham khảo trực tiếp ở README gốc).
