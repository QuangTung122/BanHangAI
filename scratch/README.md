# Scratch (Nháp & Thử nghiệm)

Thư mục này được sử dụng để chứa các đoạn mã nháp (scratch scripts), các tệp dữ liệu tạm thời, hoặc các bài kiểm tra ý tưởng nhanh (PoC - Proof of Concept) trong quá trình phát triển BanHangAI.

Các tệp trong thư mục này thường không được tích hợp trực tiếp vào môi trường sản xuất (production) nhưng lại rất hữu ích cho các lập trình viên khi cần:
- Trích xuất dữ liệu, kiểm tra API độc lập (ví dụ: `extract_chat.js`).
- Debug một đoạn logic phức tạp.
- Cấu hình tạm thời để thử nghiệm công nghệ mới.
