# Specs (Đặc tả hệ thống)

Thư mục này chứa các tài liệu đặc tả (Specifications) chi tiết về hệ thống BanHangAI, được phân tách dựa trên các giai đoạn phát triển.

## 📁 Cấu trúc thư mục

- **`requirements/`**: Đặc tả yêu cầu hệ thống.
  - Phân tích nghiệp vụ, Actor, Use Cases, User Stories.
- **`design/`**: Đặc tả thiết kế hệ thống.
  - Thiết kế kiến trúc (System Architecture, API Specs).
  - Cấu trúc cơ sở dữ liệu (ERD).
  - Điểm tích hợp AI (AI Integration Points).
  - Thiết kế giao diện (Wireframes).
  - Các đặc tả module chi tiết (POS, Installment, Cashflow, Product, Staff).
- **`testing/`**: Kịch bản và ca kiểm thử (Test Cases) cho toàn bộ hệ thống và từng module cụ thể.
- `dieu_khoan_su_dung.md`: Điều khoản sử dụng hệ thống.
