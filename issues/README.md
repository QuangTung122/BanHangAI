# Issues (Lưu vết & Quản lý Task)

Thư mục này được sử dụng để lưu trữ các tài liệu lưu vết lỗi (bugs), ghi nhận vấn đề (issues) phát sinh và quản lý các tác vụ (tasks) trong quá trình phát triển dự án BanHangAI.

## 📁 Mục đích

- Ghi nhận chi tiết các lỗi hoặc cảnh báo từ người dùng / hệ thống.
- Theo dõi các task hoặc feature request chưa được giải quyết.
- Đóng vai trò như một tracker cục bộ cho toàn dự án.

## 📝 Quy cách

- Bất kỳ lỗi hoặc vấn đề phức tạp nào cần theo dõi nên được tạo thành một file markdown riêng (ví dụ: `issue-001-login-bug.md`).
- File nên có thông tin về mô tả lỗi, cách tái hiện, trạng thái (Open, In Progress, Resolved).
